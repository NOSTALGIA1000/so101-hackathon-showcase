# SO‑ARM101 × LeRobot ACT｜桌面抓取与放置

地瓜机器人黑客松 2026 · NOSTALGIA1000 项目作品集

我用 SO‑ARM101 和 LeRobot 做桌面抓取与放置实验，沿着遥操作示教、ACT 训练、真机推理和动作复盘推进。这个项目让我把接近物体、夹稳、抬升、搬运和放置分开检查，找出动作在哪个阶段偏离预期。

## 真机完成情况

| 任务 | 实拍中完成的动作 |
| --- | --- |
| 小圆盖放置 | 从桌面夹起圆盖，搬运到紫色方块上方，放到方块顶面。人工复位后再次完成。 |
| 塑料瓶处理 | 夹住立放塑料瓶的瓶颈，抬起并改变瓶身姿态。 |

## 项目工作

- 用遥操作示教组织桌面抓取与放置任务，结合腕部和场景画面以及关节与夹爪状态。
- 用 LeRobot 的 ACT 训练动作序列策略，并在真机短测中观察接近、抓取和搬运表现。
- 排查相机视角对应和控制限幅对执行轨迹的影响，按动作阶段定位抓放偏差。

完成了真机定性演示。若要比较不同策略的抓放成功率，下一步是固定物体、初始摆位和成功判据，再保存逐轮复测记录。

## 这次黑客松想做什么

把桌面操作能力放进一台带折叠微型机械臂的移动机器人。计划以地瓜 RDK 为主控，先完成小物品归位，再尝试让机器人按语音指令找到 USB‑C 线头，夹持并移到固定支架前完成对准和插接。比赛阶段将验证微型夹爪能否在搬运时保持插头姿态，以及受阻时能否退回重试。
